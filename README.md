# Task 6: Create a Strong Password and Evaluate Its Strength

## Objective

To understand what makes a password strong and evaluate password security using online password strength checkers.

## Tools Used

* PasswordMeter (https://www.passwordmeter.com)

## Passwords Tested

| Password              | Strength    |
| --------------------- | ----------- |
| password123           | Weak        |
| Welcome2026           | Medium      |
| Welcome@2026          | Strong      |
| W3lc0me@2026!         | Very Strong |
| MyDogLovesPizza@2026# | Excellent   |

## Observations

1. Longer passwords received higher scores.
2. Passwords containing uppercase letters, lowercase letters, numbers, and symbols were stronger.
3. Common words reduced password strength.
4. Passphrases provided the best security while remaining easy to remember.

## Common Password Attacks

### Brute Force Attack

An attacker tries every possible combination until the correct password is found.

### Dictionary Attack

An attacker uses a list of commonly used passwords and dictionary words to guess passwords.

## Password Security Best Practices

* Use at least 12-16 characters.
* Include uppercase and lowercase letters.
* Use numbers and special symbols.
* Avoid personal information.
* Do not reuse passwords.
* Enable Multi-Factor Authentication (MFA).
* Use a password manager.

## Conclusion

Password complexity and length significantly improve security. Strong passwords are harder to crack using brute force and dictionary attacks. Using passphrases and MFA provides additional protection against unauthorized access.
